# Text editor actions

<a id="Undo"></a>

## ![Undo icon](images/Undo-icon.png) Undo

Shortcut: <kbd>Ctrl</kbd> + <kbd>Z</kbd> (<kbd>⌘</kbd> + <kbd>Z</kbd>)

<a id="Redo"></a>

## ![Redo icon](images/Redo-icon.png) Redo

Shortcut: <kbd>Ctrl</kbd> + <kbd>Y</kbd> (<kbd>⌘</kbd> + <kbd>Y</kbd>)

<a id="CutText"></a>

## ![Cut icon](images/CutText-icon.png) Cut

Cut the selected text to the clipboard

<a id="CopyText"></a>

## ![Copy icon](images/CopyText-icon.png) Copy

Copy the selected text to the clipboard

<a id="EditorFindPrevious"></a>

## ![Find Previous icon](images/EditorFindPrevious-icon.png) Find Previous

Find the previous occurrence of the previously searched text

Shortcut: <kbd>Shift</kbd> + <kbd>F3</kbd> (<kbd>⇧</kbd> + <kbd>F3</kbd>)

<a id="SaveAsText"></a>

## ![Save As... icon](images/SaveAsText-icon.png) Save As...

Save the text in a file (new or exising) selected in the file chooser

Shortcut: <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>S</kbd> (<kbd>⇧</kbd> + <kbd>⌘</kbd> + <kbd>S</kbd>)

<a id="SaveText"></a>

## ![Save icon](images/SaveText-icon.png) Save

Save the changes to the file

Shortcut: <kbd>Ctrl</kbd> + <kbd>S</kbd> (<kbd>⌘</kbd> + <kbd>S</kbd>)

<a id="PasteText"></a>

## ![Paste icon](images/PasteText-icon.png) Paste

Paste the content of the clipboard to the current location of the caret

<a id="EditorReplace"></a>

## ![Replace icon](images/EditorReplace-icon.png) Replace

Replace the search text with the specified replacement text

<a id="EditorReplaceAll"></a>

## ![Replace All icon](images/EditorReplaceAll-icon.png) Replace All

Replace all occurrence of the search text with the specified replacement text
