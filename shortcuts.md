# Ant Commander Pro File Manager Shortcuts

> Shortcuts only works if the action is executable and included in the version of Ant Commander (Pro or Personal edition)

## Nagivation
* <kbd>Alt<kbd> (<kbd>⌥</kbd>) + single click or `click mouse wheel` (for some mice) to navigate directories in Directory Table
* `mouse back and forward buttons` (if available): Move back and forward in the navigation history
* Go To...: <kbd>Ctrl</kbd> + <kbd>G</kbd> (<kbd>⌘</kbd><kbd>G</kbd>)
* Super Bookmark 1: <kbd>Ctrl</kbd> + <kbd>1</kbd> (<kbd>⌘</kbd><kbd>1</kbd>)
* Super Bookmark 2: <kbd>Ctrl</kbd> + <kbd>2</kbd> (<kbd>⌘</kbd><kbd>2</kbd>)
* Super Bookmark 3: <kbd>Ctrl</kbd> + <kbd>3</kbd> (<kbd>⌘</kbd><kbd>3</kbd>)
* Up: <kbd>Alt</kbd> + <kbd>UP</kbd> (<kbd>⌥</kbd> + <kbd>UP</kbd>)
* Add Bookmark: <kbd>Ctrl</kbd> + <kbd>B</kbd> (<kbd>⌘</kbd><kbd>B</kbd>)

## Panels
* `alt + right or left`: Go to the next (or previous) panel
* `(shift) ctrl + T`: Go to the next (or previous) tab
* Parent in Panel: <kbd>Shift</kbd> + <kbd>Alt</kbd> + <kbd>UP</kbd> (<kbd>⇧</kbd><kbd>⌥</kbd><kbd>UP</kbd>)
* Remove Panel: <kbd>Ctrl</kbd> + <kbd>W</kbd> (<kbd>⌘</kbd><kbd>W</kbd>)
* Preview in Panel: <kbd>Shift</kbd> + <kbd>F3</kbd> (<kbd>⇧</kbd><kbd>F3</kbd>)
* Add Panel: <kbd>Ctrl</kbd> + <kbd>N</kbd> (<kbd>⌘</kbd><kbd>N</kbd>)

## Directory Table
- <kbd>Ctrl</kbd> + <kbd>F</kbd> (<kbd>⌘</kbd><kbd>F</kbd>): Go to the search field
- <kbd>Shift</kbd> <kbd>up</kbd> or <kbd>down</kbd>: Select previous or next file
- `ctrl + A` (<kbd>⌘</kbd><kbd>A</kbd>): Select all visible files
- `INSERT` `INS`: Select or deselect current line and move to next line

For Windows:
- `ctrl + up or down `: move to the previous or next line
- `ctrl + space`: Select/Deselect current line
- `context menu` (if available on keyboard): Show context menu

## Search field
- <kbd>Enter</kbd>: Open the file (or directory) at the top of the table
- <kbd>ctrl</kbd> + <kbd>Enter</kbd> (<kbd>^</kbd> <kbd>Enter</kbd>): Show all files  and select top file (or directory), 
  if in a sub-directory, it will first go to the sub-directory
- <kbd>alt</kbd> + <kbd>A</kbd> (<kbd>⌥</kbd> <kbd>A</kbd>): Select all visible files in the table
- <kbd>Esc</kbd>: Clear the field
- <kbd>ctrl</kbd> + <kbd>H</kbd> (<kbd>^</kbd> <kbd>H</kbd>): Show help for this field

## Text Editor Pro
* <kbd>ctrl</kbd> <kbd>shift</kbd> <kbd>O</kbd>: Open files in project who's name contains the selected text or the text in clipboard
* Redo: <kbd>Ctrl</kbd> + <kbd>Y</kbd> (<kbd>⌘</kbd><kbd>Y</kbd>)
* Find Previous: <kbd>Shift</kbd> + <kbd>F3</kbd> (<kbd>⇧</kbd><kbd>F3</kbd>)
* Save As...: <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>S</kbd> (<kbd>⇧</kbd><kbd>⌘</kbd><kbd>S</kbd>)
* Save: <kbd>Ctrl</kbd> + <kbd>S</kbd> (<kbd>⌘</kbd><kbd>S</kbd>)
* Undo: <kbd>Ctrl</kbd> + <kbd>Z</kbd> (<kbd>⌘</kbd><kbd>Z</kbd>)

## Files
* Rename File: <kbd>Ctrl</kbd> + <kbd>F2</kbd> (<kbd>⌘</kbd><kbd>F2</kbd>)
* New Directory: <kbd>F7</kbd>
* Copy Files: <kbd>F5</kbd>
* Rename multiple files: <kbd>Ctrl</kbd> + <kbd>R</kbd> (<kbd>⌘</kbd><kbd>R</kbd>)
* Move Files: <kbd>F6</kbd>
* Delete permanently: <kbd>Shift</kbd> + <kbd>DELETE</kbd> (<kbd>⇧</kbd><kbd>BACK SPACE</kbd>)
* Delete: <kbd>DELETE</kbd> (macOS: <kbd>BACK SPACE</kbd>)
* Copy Path in Clipboard: <kbd>Ctrl</kbd> + <kbd>L</kbd> (<kbd>⌘</kbd><kbd>L</kbd>)

## Actions
* Execute Action: <kbd>F9</kbd>
* Execute command: <kbd>Shift</kbd> + <kbd>Ctrl</kbd> + <kbd>F9</kbd> (<kbd>⇧</kbd><kbd>⌘</kbd><kbd>F9</kbd>)
* Help: <kbd>F1</kbd>
