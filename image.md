# Image actions

<a id="ZoomOne"></a>

## ![Zoom 1:1 icon](images/ZoomOne-icon.png) Zoom 1:1

Remove any zoom

<a id="AutoRotate"></a>

## ![Rotate automatically icon](images/AutoRotate-icon.png) Rotate automatically

Automatically rotate the image to the correct orientation based on metadata of the image

<a id="ZoomReduce"></a>

## ![Zoom / 2 icon](images/ZoomReduce-icon.png) Zoom / 2

Reduce the size of the currently viewed image by half

<a id="ZoomFit"></a>

## ![Zoom Fit icon](images/ZoomFit-icon.png) Zoom Fit

Zoom the image to fit the current panel

<a id="Rotate90CCW"></a>

## ![Rotate -90° icon](images/Rotate90CCW-icon.png) Rotate -90°

Rotate the current image 90° contra clockwise

<a id="FlipH"></a>

## ![Flip horizontally icon](images/FlipH-icon.png) Flip horizontally

Flip the current image horizontally

<a id="CopyImage"></a>

## ![Copy image to clipboard icon](images/CopyImage-icon.png) Copy image to clipboard

Copy the currently view image to the clipboard

<a id="ZoomTwice"></a>

## ![Zoom 2:1 icon](images/ZoomTwice-icon.png) Zoom 2:1

Zoom to a factor 2x

<a id="FlipV"></a>

## ![Flip vertically icon](images/FlipV-icon.png) Flip vertically

Flip the current image vertically

<a id="ZoomDouble"></a>

## ![Zoom x 2 icon](images/ZoomDouble-icon.png) Zoom x 2

Double the size of the currently viewed image

<a id="Rotate90CW"></a>

## ![Rotate 90° icon](images/Rotate90CW-icon.png) Rotate 90°

Rotate the current image 90° clockwise

<a id="ZoomHalf"></a>

## ![Zoom 1:2 icon](images/ZoomHalf-icon.png) Zoom 1:2

Show the image half the size of its original size
