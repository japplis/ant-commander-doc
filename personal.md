# Ant Commander Personal

Ant Commander Personal is a free file manager for personal use.

Ant Commander Personal is a subset of Ant Commander Pro. It supports less file systems, less panels types and less actions.

### Panels
[Panels](panels.md) are used to mostly view files and directories. You can have multiple panels per tab or open one in a new window.

| Directories     | Files        | Shell            |
|-----------------|--------------|------------------|
| Directory table | Text Editor  | Command Line     |
| Directory tree  | Image Viewer |                  |
| Thumbnails      | HTML Viewer  |                  |


### File systems

[File systems](file-systems.md) are used to browse directories and view files.

| Local                   | Compressed     | Network | Other |
|-------------------------|----------------|---------|-------|
| Local disks             | zip/jar        |         | RAM   |
| USB Sticks              | tar            |         |       |
| Mounted network drives  | gzip/bzip2     |         |       |
| Shared drives/UNC Paths |                |         |       |
